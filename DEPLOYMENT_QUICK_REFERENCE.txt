PROBLEM: Errors in logs, endpoint returning 500s
───────────────────────────────────────────────

1. Stop backend:
   systemctl stop intelliresume-backend

2. Revert code:
   git checkout v1.9.0  (previous working version)

3. Restart:
   pip install -r requirements.txt
   systemctl start intelliresume-backend

4. Verify:
   curl http://localhost:8000/health

5. Check logs:
   tail -f /var/log/intelliresume/backend.log

PROBLEM: Database connection failing
─────────────────────────────────────

1. Check connection:
   psql -h prod-db.example.com -U admin -d intelliresume_prod -c "SELECT 1"

2. If migration broke DB:
   # LAST RESORT - requires backup!
   
   # Kill connections:
   psql -h prod-db.example.com -U admin << 'EOF'
   SELECT pg_terminate_backend(pid) FROM pg_stat_activity 
     WHERE datname='intelliresume_prod' AND pid <> pg_backend_pid();
   EOF
   
   # Drop & restore:
   dropdb -h prod-db.example.com -U admin intelliresume_prod
   createdb -h prod-db.example.com -U admin intelliresume_prod
   gunzip -c backup_*.sql.gz | psql -h prod-db.example.com -U admin intelliresume_prod

PROBLEM: Payment not working
──────────────────────────────

1. Check Stripe dashboard:
   https://dashboard.stripe.com/test/webhooks

2. Verify webhook handler is running:
   curl -X POST http://localhost:8000/api/stripe/webhook \
     -H "stripe-signature: test" \
     -d '{"type":"charge.succeeded"}'

3. Check webhook secret:
   grep STRIPE_SECRET_KEY .env

PROBLEM: Performance slow after deployment
─────────────────────────────────────────

1. Check backend CPU/memory:
   top → Is process using >80% CPU?

2. Check database:
   psql intelliresume_prod -c "SELECT * FROM pg_stat_statements \
     ORDER BY total_exec_time DESC LIMIT 5;"

3. Scale if needed:
   # Add more backend instances
   kubectl scale deployment intelliresume-backend --replicas=4
